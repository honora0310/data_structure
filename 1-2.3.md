## Struct
1.  **`Cell`:** Stores the attributes of each board cell, including its special type (`type`) and corresponding value (`value`).
2.  **`RouteRecord`:** Manages successful route data, including dynamically allocated dice sequences (`dice`), total turns (`turns`), and final score (`score`).
3.  **`TurnState`:** Tracks and records comprehensive state variables within a single turn (roll, from, move_to, effect, final_pos, score, bonus, penalty, shield).

## FUNCTION
1.  **Board Initialization (`record_cellboard`):** 
    Initializes all board cells and reads special cell configurations (`id`, `type`, `val`) into the board array.
2.  **Effect String Formatting (`effect_string`):** 
    Concatenates multiple effects triggered within the same turn using semicolons.
3.  **Special Cells & Chained Effects (`special_effect`):** 
    Handles special cell types (Ladders `L`, Snakes `S`, Shields `H`, Penalties `P`, Bonuses `B`, and Treasures `T`), processes chained effects in order of arrival, and manages snake blockage with shields.
4.  **Penalty Placeholder (`current_penalty_next_placeholder`):** 
    Serves as a helper wrapper function for managing penalty values during recursive state transitions.
5.  **Mission Simulation (`DFS`):** 
    Uses a Depth-First Search (DFS) approach to enumerate all possible movement sequences within the maximum moves `R`, tracking scores, bonuses, penalties, shields, and collected treasures.
6.  **Route Evaluation & Summary (`print_successful_routes`):** 
    Filters and outputs successful routes that meet the goal criteria, prints detailed turn states, and calculates the summary (total successful routes, shortest route, and highest score).

## Input & Output
*   **Input**
    *   `int N, K, R, C, G;` // board size, max move value, max turns, number of special cells, min score required.
    *   `C` lines containing special cell configurations: `<cell_index> <type> <value>`
*   **Output**
    *   `Route X:`
    *   `Dice: d1 d2 ...`
    *   `Turn i: ...`
    *   `Result: Win in T turns, score=S`
    *   `Summary:` (Total successful routes, shortest route, and highest score)
    *   Outputs `No successful route` if no path meets the criteria

## Note
*   **Common:** Pre-deals with potential data/overflow edge cases during state updates.
*   **Time Complexity:** O(K^R) in the worst case for exploring all possible dice roll combinations.
*   **Space Complexity:** O(N + R) for storing board layouts, treasure tracking states, and recursive DFS call stacks/paths.
