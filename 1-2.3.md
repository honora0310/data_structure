## FUNCTION
1.  **Mission Simulation (`DFS`):** 
    *   Uses a Depth-First Search (DFS) approach to enumerate all possible movement (dice roll) sequences within the maximum moves `R`.
    *   Simulates the player's movement from cell 1 to cell `N`, keeping track of score, bonuses, penalties, shields, and collected treasures.
2.  **Special Cells & Chained Effects (`special_effect`):** 
    *   Handles various special cell types including Ladders (`L`), Snakes (`S`), Shields (`H`), Penalties (`P`), Bonuses (`B`), and Treasures (`T`).
    *   Processes chained effects correctly in the order of arrival when a Ladder or Snake moves the player to another special cell.
    *   Manages snake blockage when a shield is active.
3.  **Route Evaluation & Summary (`print_successful_routes`):** 
    *   Filters successful routes that reach or pass cell `N` within `R` turns and meet the minimum score requirement `G`.
    *   Outputs the detailed state of each turn, followed by a summary displaying total successful routes, the shortest route, and the highest score route.

## Input & Output
*   **Input**
    *   `int N, K, R, C, G;` // board size, max move value, max turns, number of special cells, min score required.
    *   `C` lines containing special cell configurations: `<cell_index> <type> <value>`
*   **Output**
    *   Prints each successful route's dice sequence, turn-by-turn detailed states, and final results.
    *   Outputs a summary block with total successful routes, shortest route, and highest score.
    *   Outputs "No successful route" if no valid path meets the criteria.

## Note
*   **Time Complexity:** O(K^R) in the worst case for exploring all possible dice roll combinations.
*   **Space Complexity:** O(N + R) for storing board data, visited/treasure states, and recursive DFS call stack/dice paths.
