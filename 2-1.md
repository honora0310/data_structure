## FUNCTION
1.  **Stack-based Path Exploration & Backtracking (`path_stack` & `movement_stack`):**
    *   Each robot maintains its own movement stack to track the exploration path.
    *   Direction priority order: **Up $\rightarrow$ Left $\rightarrow$ Down $\rightarrow$ Right** (`{-1, 0}`, `{0, -1}`, `{1, 0}`, `{0, 1}`).
    *   **Push:** Moves to the first unvisited valid neighboring cell (not a wall `#` and within boundaries) and pushes the coordinate onto the stack.
    *   **Pop (Backtrack):** If no valid neighbors exist, it pops the stack to return to the previous position. If backtracked to the starting cell with no further moves, status becomes `"NO PATH"`.
2.  **Round-based Simulation (`simulate_round`):**
    *   Iterates through all `ACTIVE` robots per round.
    *   Updates the occupant mapping `cell_occupant` after moving.
    *   Checks if the evacuation exit `E` is reached; if so, status updates to `"WIN"`.
3.  **Collision Handling (`crush`):**
    *   If a robot moves into a cell already occupied by another active robot:
        *   The robot with **higher health** survives; the other robot status becomes `"DIE"`.
        *   The winner gains a win count (`win_counter++`) and loses health equal to its current `win_counter`. If health drops to $\le 0$, the winner also becomes `"DIE"`.
        *   If both robots have **equal health**, both become `"DIE"`.

## Note
*   **Time Complexity:** $\mathcal{O}(K \cdot R \cdot C)$ where $K$ is the number of robots, and $R \times C$ is the grid size (each robot visits each cell at most a constant number of times during DFS exploration).
*   **Space Complexity:** $\mathcal{O}(K \cdot R \cdot C + K \cdot L)$ for the 3D visited array and path stacks (where $L$ is `MAX_PATH_LENGTH`).
