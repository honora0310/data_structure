## FUNCTION

1. **Queue Management (`Queue`, `queue_push`, `queue_pop`):**
   * Implements an array-based linked list queue using `nextJob` pointers to manage print jobs waiting for each printer without dynamic node allocations.
   * Tracks total waiting pages dynamically (`q->pages`) to allow fast estimation of workload.

2. **Workload Estimation & Printer Selection (`estimate`, `choose`):**
   * **`estimate(i, t, pages)`:** Predicts the completion timestamp if a job of given page count is assigned to printer $i$. It considers:
     * Whether the printer is currently resting (adds remaining cooling time until `restEnd`).
     * The remaining printing time of the current active job (`jobRem[curJob] * speed`).
     * Accumulated queue pages plus new job pages multiplied by the printer's `speed`.
   * **`choose(t, pages, skip)`:** Selects the printer with the earliest estimated finish time (ties broken by smaller printer ID), optionally skipping a specific printer (used during overheat reassignment).

3. **Discrete Event Simulation (`main` event loop):**
   * Advances simulation time `t` to the earliest event among:
     * Next job arrival time.
     * Job segment completion or overheat threshold reach (`event_time`).
     * Printer cooldown completion (`restEnd`).
   * **Priority Handling per Timestamp:**
     1. **COMPLETE / PREEMPT:** Updates printed pages. If remaining pages equal $0$, marks complete; otherwise queues for reassignment.
     2. **OVERHEAT:** If consecutive page count reaches `heatLimit`, marks printer resting until $t + \text{restTime}$.
     3. **REST END:** Cools down resting printers and resets the page counter to $0$.
     4. **ARRIVE:** Enqueues newly arriving jobs sorted by arrival time and job ID.
     5. **REASSIGN:** Reallocates interrupted jobs to the best alternative printer (excluding the overheated source).
     6. **ASSIGN:** Dispatches new arrivals to optimal printers.
     7. **START / IDLE:** Pulls jobs from queues to start printing; resets page counters if a printer is idle.

* **Input**

    ```c

        scanf("%lld %lld", &arrival[j], &jobRem[j]);
    }
    ```

* **Output**
  * Log lines printed chronologically at event occurrences:
    ```c
    printf("Time %lld: COMPLETE Job %d in Printer %d\n", t, j, i);
    printf("Time %lld: OVERHEAT Printer %d, Restart time=%lld\n", t, overheated[k], p->restEnd);
    printf("Time %lld: REST END Printer %d\n", t, i);

    ```

## Note

* **Time Complexity:** $\mathcal{O}(E \cdot M + N \log N)$
  * Sorting job arrivals takes $\mathcal{O}(N \log N)$.
  * In each simulation step, finding the minimum next event time takes $\mathcal{O}(M)$, and choosing the optimal printer takes $\mathcal{O}(M)$. With $E$ total discrete events ($E \le \mathcal{O}(N \cdot (\text{max\_pages} / \text{heatLimit}))$, the simulation runs efficiently.
* **Space Complexity:** $\mathcal{O}(M + N)$ to store printer states, queues, and job information.
